## 📊 Market Performance Analysis Dashboard

### A modern and interactive Power BI dashboard to analyze sales, brand performance, transactions, and market trends over time.

---

### 🚀 Overview

The **Market Performance Dashboard** provides an end-to-end view of product sales, returns, and customer behavior over time. It is built using Power BI and enables stakeholders to make data-driven decisions based on interactive KPIs and dynamic visualizations.

---

### 📌 Key Features

- 📈 **Sales Trend Line Chart**: Visualizes revenue fluctuations over time (monthly).
- 📦 **Product Brand Performance**: Highlights top brands and groups low performers under "Others."
- 🧮 **KPIs**: Real-time stats for Total Transactions, Sales Revenue, and Returns with growth indicators.
- 🌍 **Region-Level Filters** (optional): Filter performance by geographical location.
- 🧰 **Drill-through Analysis**: Navigate from summary to detailed views.
